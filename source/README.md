# SA Tank Battle — Source files

This folder contains selected source files that can be shared separately from the playable website.

## Included
- `css/style.css` — interface and visual styling.
- `js/state.js` — player progression, vehicle unlocks, presets, and saved game state.
- `js/sound.js` — original stylised game audio code.

## Important
This is **not a standalone copy of the complete development project**. The playable public build remains in the repository root and its `assets/` folder.

Some game simulation modules are intentionally not included in this public source sample. The full development project remains in the private repository. Continue making and testing game changes there, then publish the built `dist/` output to keep the public website updated.
